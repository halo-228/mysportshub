연동 설정

일정 동기화 버튼으로 전체 수집하기

평소엔 매일 03:00·15:00에 자동으로 전체 일정을 수집해요. 상단 일정 동기화 버튼으로 지금 바로 수집하려면 GitHub 토큰이 한 번 필요해요. 토큰은 이 기기 브라우저에만 저장돼요.

  1. GitHub 토큰 만들기 열기 (로그인 필요)
  2. Token name: MySportsHub · Expiration: 1년 (또는 원하는 기간)
  3. Repository access: Only select repositories → 이 사이트 저장소 선택
  4. Permissions → Repository permissions → Actions: Read and write
  5. Generate token → 나온 github_pat_… 를 아래에 붙여넣기

네이버 일정 링크 팀코드

"네이버 중계/일정" 버튼은 그 팀의 그 달 첫 경기 날짜 + 팀코드로 한 달 내내 고정돼요. 팀코드가 비어 있으면 대회 전체 일정으로 열려요.
네이버 스포츠에서 팀을 눌렀을 때 주소의 teamCode= 숫자를 넣으면 이 기기에 저장돼요.
캘린더 구독

구독해 두면 휴대폰·PC 캘린더에 그 팀 경기가 자동으로 들어오고, 일정이 바뀌면 캘린더도 몇 시간 안에 따라 바뀌어요. 끝난 경기 제목엔 점수가 붙어요.

구글 캘린더는 휴대폰 앱이 아니라 PC 브라우저에서 추가해야 해요(추가 후엔 휴대폰에도 보여요). 아이폰은 "아이폰" 버튼을 누르면 바로 구독돼요.
